
# Recursos digitales

Esta sección contendrá el kit digital
de apoyo para los participantes.

## Materiales del taller

- Ejemplos de planos arquitectónicos.
- Documentos técnicos de muestra.
- Bitácoras de obra.
- Evidencias fotográficas.
- Plantillas para informes.
- Ejemplos de instrucciones para IA (prompts).

## Herramientas de inteligencia artificial

Se incorporará un catálogo de herramientas
con sus aplicaciones, requisitos de acceso
y limitaciones.

## Consideraciones

Los documentos utilizados en las prácticas
serán ejemplos didácticos o materiales
autorizados para su uso.

No se deberán cargar documentos confidenciales
o datos personales en herramientas externas
sin la autorización y las salvaguardas necesarias.
