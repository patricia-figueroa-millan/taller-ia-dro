
# Actividades prácticas

En esta sección se publicarán las actividades
demostrativas y participativas del Taller IA-DRO.

## Actividades previstas

1. Análisis de documentación técnica con IA.
2. Consulta asistida de normativa.
3. Análisis de evidencias de supervisión de obra.
4. Generación de informes técnicos.
5. Aplicaciones de visualización arquitectónica.

Cada actividad incluirá:

- Objetivo.
- Materiales necesarios.
- Herramienta de IA.
- Instrucciones paso a paso.
- Resultado esperado.
- Criterios de revisión profesional.

> Las actividades se incorporarán progresivamente.
